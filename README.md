# Història de 2n de Batxillerat

Web dels sis temes de Història d'Espanya i Catalunya que entren a les PAU.

- Web pública: https://guillembaro-tech.github.io/historia-2batx/
- Panell d'administració: https://guillembaro-tech.github.io/historia-2batx/admin/

El contingut de cada tema és a `content/temes/tema-N.json` i les imatges a `media/`. S'editen des del panell d'administració.

El menú de capçalera és a `assets/menu.js`: per afegir-hi o canviar-hi una entrada, només cal editar aquest fitxer.

El Taller PAU és a `taller.html`. El contingut de cada tema del taller és a `content/taller/tema-N.json`; un tema apareix com a disponible quan hi posa `"estat": "disponible"`.
