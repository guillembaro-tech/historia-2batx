# Imatges destacades de les unitats

Dibuix de línies del color del curs sobre el to suau del curs (colors de `uploads/pds-model/pds-v4.css`), 1600 × 900 px, PNG.

- `dibuixos.js`, els dibuixos (viewBox 420 × 240). Els de 1r i 2n d'ESO són els de les capçaleres de `model4.css` (`.um-t-<codi>`) i els de 2n de Batxillerat, els de `tema-v4.css` (`.pds2-t-N`). La resta són nous.
- `unitats.json`, el post de cada unitat o tema, el curs, el dibuix, el fitxer i el text alternatiu.
- `build.js`, genera els PNG (`npm i sharp`, `node build.js`).
- `totes.png`, full de contacte.
